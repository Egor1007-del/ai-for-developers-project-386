# Использовать Bootstrap для оформления интерфейса

Чтобы сохранить интерфейс единообразным и простым в поддержке, используем компоненты и утилитарные классы Bootstrap вместо собственной системы стилей или другой UI-библиотеки. Если средствами Bootstrap не удаётся получить нужный результат, сначала обсуждаем варианты с владельцем проекта; добавлять кастомные стили можно только с его разрешения.
