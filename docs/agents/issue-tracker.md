# Issue tracker: GitHub

Задачи и спецификации хранятся в GitHub Issues репозитория
`Egor1007-del/ai-for-developers-project-386`. Используйте подключённый
GitHub MCP для чтения, создания и изменения задач и комментариев.

## Соглашения

- Создавайте задачи только в указанном репозитории.
- Используйте GitHub sub-issues для связи дочерних задач с родительскими.
  Если это недоступно, добавляйте `Part of #<номер>` в начало дочерней задачи.
- Для зависимостей используйте встроенные GitHub issue dependencies, если
  доступен подходящий инструмент. Иначе указывайте
  `Blocked by: #<номер>, #<номер>` в начале задачи. Задача разблокирована,
  когда все блокирующие задачи закрыты.
- При закрытии задачи оставляйте комментарий с объяснением и указывайте
  причину закрытия.
- Метки triage определены в `docs/agents/triage-labels.md`.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## Публикация и получение задач

Когда скилл предлагает опубликовать задачу, создайте GitHub issue.
Когда требуется получить тикет, прочитайте соответствующую GitHub issue
вместе с её комментариями и метками.

## Wayfinding

Карта — issue с меткой `wayfinder:map`; её дочерние задачи связываются
через GitHub sub-issues и получают метку `wayfinder:<type>`. Если sub-issues
недоступны, добавляйте дочерние задачи в список карты и указывайте
`Part of #<номер>` в их описании. Для выбора следующей задачи исключайте
назначенные задачи и задачи с открытыми блокирующими зависимостями.
При взятии задачи назначайте её себе. При завершении оставляйте ответ
комментарием, закрывайте задачу и добавляйте ссылку на результат в карту.
