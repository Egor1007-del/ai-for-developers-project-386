# Triage Labels

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | `needs-triage` | Задача ожидает оценки |
| needs-info | `needs-info` | Нужна дополнительная информация |
| ready-for-agent | `ready-for-agent` | Задача готова к выполнению агентом |
| ready-for-human | `ready-for-human` | Требуется выполнение человеком |
| wontfix | `wontfix` | Задача не будет выполняться |

Когда скилл упоминает роль, используйте соответствующую метку из таблицы.
