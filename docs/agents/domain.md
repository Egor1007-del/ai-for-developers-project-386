# Domain Docs

## Перед изучением кода

Читайте `GLOSSARY.md` в корне и относящиеся к задаче решения из `docs/adr/`.
Если этих файлов ещё нет, продолжайте работу без предупреждения:
скилл domain-modeling создаёт их по мере необходимости.

## Структура

Проект использует единый контекст: корневой `GLOSSARY.md` и `docs/adr/`.

## Терминология и решения

Используйте термины из глоссария в задачах, предложениях и тестах.
Если подходящего термина нет, отметьте пробел для domain-modeling.
Если предложение противоречит существующему ADR, явно укажите это
и объясните причину возможного пересмотра.
